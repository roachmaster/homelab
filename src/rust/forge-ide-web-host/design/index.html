Workspace data flow

  1. Browser

    Keeps a random tab identifier in session storage and requests a saved workspace.

  2. Forge web host

    Checks the active session, request origin, and CSRF token before forwarding.

  3. Agent Runner

    Validates the checkpoint, tab lease, and save revision.

  4. PostgreSQL

    Stores the operator’s Chat history and separate tab checkpoints.
